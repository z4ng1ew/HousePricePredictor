# House Price Prediction (Ценоискатель)

Простая модель машинного обучения для предсказания цены квартиры на основе площади и количества комнат с использованием линейной регрессии.

## 📌 Описание
Проект генерирует синтетические данные о квартирах, обучает модель линейной регрессии и оценивает её качество с помощью метрик:
- MSE (среднеквадратичная ошибка)
- R² (коэффициент детерминации)
- MAPE (средняя абсолютная процентная ошибка)

Также включает анализ:
- Самых дорогих и дешёвых квартир по количеству комнат
- Сохранение и загрузку модели через `joblib`

## 🛠 Технологии
- Python
- pandas, numpy
- scikit-learn
- joblib

## ▶️ Как запустить
1. Установите зависимости:  
   ```bash
   pip install pandas numpy scikit-learn
   ```
2. Запустите скрипт:
   ```bash
   python house_price_prediction.py
   ```

## 💾 Модель
Обученная модель сохраняется в файл `linear_regression_model.joblib` и может быть загружена позже для новых предсказаний.

## 📊 Пример вывода
```
1-комнатные квартиры:
Самая дешёвая: цена=1845000.0, Площадь=52.0
Самая дорогая: цена=7922646.0, Площадь=181.0
```
